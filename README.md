
# Анализ пространственно-временных данных о работе уборочной техники Санкт-Петербурга

Проект посвящён анализу пространственно-временных данных о работе уборочной техники Санкт-Петербурга. Цель исследования - выявление закономерностей активности техники, анализ её перемещений и прогнозирование количества активных машин в районах города.

**Участники:**

**Группа:** 5040102/60201

## Задачи проекта

1. **Анализ активности техники** по районам Санкт-Петербурга, времени суток, дням недели и видам выполняемых операций.
2. **Восстановление рабочих сессий и траекторий** машин с оценкой продолжительности движения и остановок.
3. **Выявление редко посещаемых участков** и территорий с длительными интервалами между повторными наблюдениями техники.
4. **Обнаружение аномалий** в данных: резких скачков координат, длительной неподвижности и нетипичного времени активности.
5. **Прогнозирование количества активных машин** в районах на следующий час с учётом временных факторов и погодных условий.

## Данные

**Источник:** [Портал уборочной техники Санкт-Петербурга](https://ut.kb.gov.spb.ru/)

На текущий момент собраны данные за 8 дней. Данные представлены в форматах `.csv` и `.csv.gz` и содержат информацию о местоположении и активности уборочной техники.
