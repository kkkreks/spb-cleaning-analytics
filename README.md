## Описание проекта
Система анализа GPS-телеметрии уборочной техники Санкт-Петербурга. 
Цель — выявление закономерностей активности, анализ перемещений и прогнозирование количества активных машин.

## Решаемые задачи
1. **Анализ активности техники** по часам, дням недели, видам операций.
2. **Восстановление рабочих сессий** и траекторий.
3. **Выявление редких зон** и длинных интервалов между визитами.
4. **Обнаружение аномалий** (скачки координат, длительная неподвижность).
5. **Прогноз активности** на час вперёд (LightGBM).

## Стек технологий
* **ETL:** Python, DuckDB, Pandas
* **Аналитика:** H3, LightGBM, Matplotlib/Seaborn
* **Big Data:** PySpark, HDFS (Docker)

## Структура проекта
* `src/etl/` — скрипты очистки и подготовки данных (Parquet).
* `src/analytics/` — решение 5 задач анализа.
* `src/big_data/` — демонстрация работы с PySpark и HDFS.
* `src/report/` — генератор отчета и HTML-презентация.
* `figures/` — результаты визуализации (28 графиков).

## Запуск
1. Установите зависимости: `pip install -r requirements.txt`
2. Запустите ETL: `python src/etl/build_all_clean.py`
3. Запустите аналитику: `python src/analytics/task_1_activity.py` (и так далее).
